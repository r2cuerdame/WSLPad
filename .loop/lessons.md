# 운영에서 보존할 사실

- 소스 1.2.0과 공개 1.1.2는 다른 상태다. CI 성공을 공개 릴리스 완료로 보고하지 않는다.
- `docs/RELEASING.md`와 #107의 격리 조건을 따른다. 사용자 세션에서 설치/삭제/업그레이드 검증을 대신하지 않는다.
- KPI 기록과 machine 댓글은 구현 요청이 아니다. 과거 실행 도구나 조직/원장을 새 루프로 가져오지 않는다.
- 프로젝트별 제품 원칙은 `.github/CONTRIBUTING.md`를 따른다. 시스템 변경은 사용자에게 준비만 하고, 모름을 0으로 바꾸지 않으며 MCP는 읽기 전용이다.
