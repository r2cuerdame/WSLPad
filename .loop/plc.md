# WSLPad 제품 수명주기 계획

이 문서는 WSLPad의 제품 수명주기를 한 장으로 안내하는 정본이다. 계획은 현재 저장소와 LoopOffice 운영 스냅샷에서 확인한 사실을 구분해 갱신한다. 스냅샷은 읽기 전용 사본이며 GitHub의 이슈·마일스톤과 canonical checkout이 운영 원장이다.

## 지금의 기준

- 제품: Windows에서 WSL의 실제 상태를 보여 주는 작은 동반 도구. Dashboard, Windows↔WSL Explorer, Console, 읽기 전용 MCP를 제공한다.
- 단계와 플랫폼: 출시됨, Windows. `.loop/project.md`에 기록된 공개 기준 버전은 1.1.2이며, `package.json`의 소스 버전은 1.2.0이다. 소스 버전은 공개 출시를 뜻하지 않는다.
- 현재 목표와 다음 이정표: `# WSLPad PD`, 2026-11 (마감 2026-11-30). 2026-11-07 운영 스냅샷 기준 9개 중 4개 완료, 5개 열림이다.
- 실제 작업: 같은 스냅샷에서 #132 “PLC: 제품 수명주기 한 장 계획 제안”이 실행 중으로 기록되어 있다. 이슈와 마일스톤의 최종 상태는 GitHub 원장을 따른다.
- 배포: `.loop/project.md`에 `deployWorkflow: not_required`로 기록되어 있다. 공식 릴리스는 수동 절차이며 이 계획은 배포나 릴리스 게시를 시작하지 않는다.

## 수명주기

```mermaid
flowchart LR
 A[현재 제품과 실제 이슈] --> B[안정성·유지보수]
 B --> C[다음 마일스톤 검증]
 C --> D[다음 버전·아이디어 제안]
 D --> E{오너 승인}
 E -->|승인| F[기능 구현과 출시 검증]
 F --> A
 E -->|대기| B
```

버그·안정성·유지보수와 이미 승인된 마일스톤 작업은 기존 동작을 확인하고 로컬 검증을 거쳐 진행한다. 새 기능, 비용 발생, 보안 정책 또는 제품 방향 변경은 제안으로 남기고 오너 승인 후 시작한다. 제품 변경은 실제 이슈와 마일스톤을 근거로 우선순위를 정한다.

## 다음 판단과 제약

- 2026-11 마일스톤의 열린 이슈와 완료 조건을 GitHub에서 확인하고, 빈 작업 대기열에서는 검증 가능한 안정성·유지보수 근거를 찾는다.
- README의 VHDX Console 명령 준비와 ARM64 빌드는 공개 로드맵 항목이다. 승인된 범위로 간주하지 않으며, 다음 버전 포함 여부는 별도 오너 결정이 필요하다.
- 기존 PC·구독 자원과 자원 관리자 한도 안에서 프로젝트 PD 하나로 진행한다. 상태 스냅샷에 기록된 슬롯은 1개이며, 계정 사용량 창과 개별 리소스 heartbeat/log 카운터는 제공되지 않거나 알 수 없음으로 취급한다. 숫자를 추정하지 않는다.
- 새 유료 자원이나 인프라는 승인 전 도입하지 않는다. 사용자에게 보이는 기능·제품 방향·보안 정책을 임의로 확정하지 않는다.

## 완료와 갱신

기본 흐름은 이슈 → 작업 브랜치 → 구현 → 로컬 검증 → PR → 독립 검토와 머지 → 필요한 경우 공식 릴리스와 프로덕션 검증이다. 이 프로젝트는 자동 배포가 필요하지 않다고 설정되어 있으므로 릴리스가 필요한 경우 기존 수동 릴리스 절차를 따른다. 매 마일스톤 판단 때 실제 이슈·마일스톤, 공개 출시 버전과 소스 버전을 각각 확인해 이 문서를 갱신한다. 불확실한 상태와 텔레메트리는 unknown으로 남긴다.
